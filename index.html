01

分析目标、范围与系统边界

分析目标

识别 Roadster Rocket 在演示、体验与潜在运行场景中的危险与失效路径，评估风险水平，提出可验证的安全需求与缓解措施，并指出现有公开证据下的残余风险与安全论证缺口。本报告不替代适航审定、碰撞试验或第三方独立安全审查。

系统边界（依据公开信息重构）

车载系统（分析范围内）

车身 / 座舱 / 约束系统 底盘 / 悬架 动力电池与电气 COPV 高压气瓶组 10 个冷气推力器 阀门 / 喷口 / 风扇 姿态感知与飞控

运行环境（外部接口）

封闭场地 / 试验场 地面人员与观众区 气象与阵风 地面效应与障碍物 补气 / 检测作业区 遥控 / 演示操作人员

边界外（不臆测）

未公开控制拓扑 冗余架构细节 气瓶压力等级 安全裕度数据 未披露试验记录
关键前提：公开视频只能证明“演示条件下发生了受控抬升与姿态响应”。安全完整性等级、冗余独立性、可靠度与适航符合性均无公开证据，下文相关结论以“待验证缺口”而非“已具备能力”表述。

适用标准与安全工程框架

Roadster Rocket 同时携带高压气瓶、多个推力器、载人座舱与道路行驶功能，不能只按汽车或航空器其中一套逻辑设计。分析同时借鉴道路车辆功能安全、预期功能安全与航空器适航三类方法。

标准 / 框架关注点在本案例中的作用
ISO 26262 道路车辆功能安全E/E 系统故障导致的不合理风险；ASIL 等级分解、安全需求与验证指导电气、控制与推力执行系统的故障安全论证与安全完整性分级
ISO 21448 (SOTIF)无系统故障时，由功能不足、性能边界与可预见误用引起的风险识别感知局限、模式误解、低空阵风、人员位置判断等非故障风险
ISO 34502 场景安全评价框架任务—场景—危险—控制措施—验证方法的场景化映射组织倒置坡道、越障、围观、补气等极端场景的评价证据
EASA SC-VTOL垂直起降航空器专用条件与符合性方法对照航空器级失效概率、冗余与持续适航要求，衡量差距
FAA powered-lift / Part 103动力升力航空器认证运行；超轻型航空器边界判断监管归类与运行许可路径；目前未见任一类别正式批准证据
ARP4754A / ARP4761 思路民用航空器开发过程与安全性评估（FHA / FTA / FMEA / CCA）组织从功能危险评估到冗余与共因分析的安全性评估链条
标准不是“飞行汽车认证证书”，而是把危险、场景、性能限制与验证证据组织起来的方法。若仅在封闭场地完成表演，路径更接近试验 / 表演 / 特殊许可；若进入公共道路、开放空域或商业载客，软硬件要求将显著升级。

危险识别：能量源与 HAZOP 引导词分析

系统安全分析先识别可致害的能量源，再以 HAZOP 引导词（多 / 少 / 反向 / 非预期 / 缺失 / 早 / 晚）逐项排查功能偏离。本案例主要能量源包括：高压压缩气体能、动力电池电能、运动 / 动能、喷流与噪声能、重力势能。

引导词偏离的功能可能危险状态主要受影响对象
多 / 过高气瓶充注压力、推力指令、姿态角速度超压、非预期强推力、姿态过激翻覆乘员、结构、地面人员
少 / 不足推力输出、补气量、制动 / 阻尼升力不足坠落、落地冲击过大、控制裕度丧失乘员
反向 / 不对称推力方向、左右 / 前后推力分配偏航 / 翻滚、非预期位移乘员、周边人员与设施
非预期推力器点火、模式切换、风扇启动地面非预期抬升、误闯入危险区地面人员、车辆
缺失阀门开启、传感器信号、控制指令、中止指令推力丧失、姿态估计错误、无法终止动作乘员、地面人员
早 / 晚 / 卡滞阀门启闭、推力时序、模式过渡时序错误、执行器卡滞、模态衔接失控乘员、结构

危险域清单

  • 压力系统危险：爆破、泄漏、冲击损伤、应力破裂、过热失强、过充。
  • 推力与控制危险：姿态失控、非预期抬升、推力不对称、执行器卡滞、传感器冲突、通信丢失。
  • 人员安全危险：乘员碰撞 / 翻覆伤害、地面人员被撞击、喷流与噪声伤害、应急撤离受阻。
  • 运行与监管危险：道路不可合法行驶、航空运行未获许可、人员无资质操作、场地隔离不足。

故障树分析（FTA）：顶事件“空中姿态失控并撞击地面 / 人员”

顶事件 TE：车辆空中姿态失控，撞击地面、设施或地面人员
OR（任一中间事件发生，且未能被故障安全机制阻止）
M1 推力 / 升力异常
  • 推力不足或总冲量耗尽
  • 多路推力不对称
  • 阀门卡滞 / 喷口堵塞
  • 非预期推力点火
M2 姿态控制失效
  • 姿态传感器失效 / 冲突
  • 推力分配解算错误
  • 执行器响应超限
  • 链路丢失且无独立中止
M3 压力 / 能量系统失效
  • COPV 爆破 / 大量泄漏
  • 过充 / 超压
  • 受热失强
  • 补气不足导致推力断供
M4 外部诱发因素
  • 阵风 / 地面效应突变
  • 障碍物净空不足
  • 人员侵入危险区
  • 模式误用 / 非授权抬升

逻辑说明与共因关注

  • M1 与 M2 常耦合出现：推力不对称会先扰动姿态，若控制重构失败才发展为失控；分析时需区分“可被重构吸收的扰动”与“超出降级包线的失效”。
  • 共因失效（CCA）关注：共用气源导致多路推力同时衰减；同一供电 / 计算通道影响多个推力器；传感器安装与算法共因偏差。
  • 顶事件能否发生，还取决于屏障层是否有效：抬升互锁、场地隔离、故障安全模式、应急泄压与地面救援。FTA 应把屏障作为抑制事件纳入后续定量分析。
现有公开材料未提供各底事件发生概率、冗余独立性与共因系数，因此本树为定性结构树；定量最小割集与概率排序需待设计数据与试验记录补充。

压力系统（COPV）专项安全分析

失效机理

  • 复合材料损伤：纤维断裂、基体开裂、界面脱粘、分层与局部冲击损伤，会逐步降低剩余强度。
  • 应力破裂：长期承压与重复充放下，复合材料可能发生延迟失效。
  • 热—结构耦合：气体快速膨胀吸热形成低温区；外部火灾又会降低树脂与纤维性能。
  • 道路环境载荷：石击、涉水、盐雾、振动与维修误操作，是传统航空气瓶维护程序未完全覆盖的场景。

必须验证的安全证据（当前公开缺口）

  • 工作压力、爆破压力与爆破裕度；温度适用范围。
  • 充放循环寿命、老化与定期检测方法（NDI）。
  • 碰撞、跌落与冲击损伤后的剩余强度判据。
  • 泄漏检测、应急泄压路径与隔离阀逻辑。
  • 起火 / 受热场景下的响应时间与退役判据。
布置在乘员舱、底盘与车身空隙中的 COPV，设计问题已从“能装多少气”升级为“如何证明在碰撞、热、疲劳、制造缺陷与重复充放条件下不会形成不可接受风险”。在上述证据缺失时，不应给出可靠性或安全性结论。
08

推力控制与冗余容错

控制链条与失效关注点

  • 姿态估计：多源感知（惯性、视觉 / 其他）交叉校验，识别传感器失效与冲突；缺乏冗余时，单传感器偏差即可误导控制。
  • 推力分配：依据质心、气动中心、剩余气量与姿态误差实时分配多路推力；部分推力器失效后需重新分配剩余控制能力。
  • 容错降级：明确各失效组合下的降级包线（可维持姿态 / 可受控落地 / 需中止动作），避免在超出能力时继续执行任务。
  • 独立监控与中止：应有独立于主控的监控通道与机载中止逻辑，在链路丢失、指令异常或状态越界时触发安全状态。

待验证能力（演示视频无法证明）

闭环抗风能力、故障重构、软硬件独立性、传感器交叉校验、执行器卡滞检测与任务中止能力，是从“表演可控”走向“运行可信”的分界线。建议通过故障注入试验、硬件在环仿真与可重复外场试验逐项验证，并公开失效后的姿态响应与着陆结果。

09

乘员与地面人员安全

乘员安全

  • 约束系统：适合高动态姿态动作的安全带 / 头盔 / 束缚方案，限制相对位移。
  • 结构与吸能：座舱翻滚保护、着陆冲击吸能、座舱生存空间保持。
  • 状态告知：模式、姿态、剩余气量与中止条件对操作人员 / 乘员清晰可见。
  • 应急撤离：出口可达、解脱快速、遇险后撤离路径与救援方案明确。

地面人员与第三方安全

  • 隔离区：按推力喷流、飞溅物与可能坠落范围划定净空区，物理围挡 + 电子围栏。
  • 喷流与噪声：喷射方向避开人员区；评估噪声频谱、频次与短时脉冲暴露。
  • 侵入联锁：人员进入危险区时禁止抬升 / 自动进入安全状态。
  • 运行组织：操作人员资质、天气窗口、现场监护、消防与残骸处置预案。
公开表述中“安全不是 Roadster 的首要目标”属于营销语境；工程语境下，低优先级不等于可以缺少最低安全论证。任何载人飞行演示都必须定义人员隔离、故障处置与事故后果边界。

SOTIF 与可预见误用：场景—危险—控制—验证映射

许多风险不一定来自硬件故障，而可能来自环境感知不足、驾驶员对模式边界的误解、低空阵风、地面人员位置判断、自动补气状态错误，或系统在复杂地面条件下错误触发。按 ISO 21448 识别这些可预见的功能不足与合理误用，并按 ISO 34502 建立场景化评价。

双重监管身份分析

道路车辆安全围绕碰撞、制动、电池、电气与功能安全展开；航空安全则要求更严格的失效概率、冗余架构、持续适航与运行控制。Roadster Rocket 横跨两套体系，二者的事故单位、暴露人群与可接受概率不同，不能用一句“航空级安全”简单合并。

监管维度道路车辆侧要求航空器侧要求当前公开状态
身份归类机动车公告 / 豁免；碰撞与电磁等准入动力升力 / 垂直起降 / 超轻型等类别认定未见正式归类与批准证据
设计安全ISO 26262 功能安全；碰撞与电池安全SC-VTOL / powered-lift 失效概率与冗余安全论证未公开
运行许可公共道路行驶资格空域使用、运行人与机组资质未取得公开运行许可
持续安全召回、检测与维修体系持续适航、维修大纲与记录维护 / 检测体系未披露
若仅在封闭场地完成表演，监管路径可能更接近试验、表演或特殊许可；若进入公共道路、开放空域或商业载客，软硬件、人员资质与运行体系要求将显著升级。

安全案例骨架与关键安全需求

安全案例应在概念阶段即建立骨架，而不是产品定型后补文件。它至少包括：任务与运行环境、系统边界、危险清单、风险接受原则、关键安全需求、独立验证方法与残余风险说明。

顶层安全目标

G1

防止非受控离地

仅在授权模式、隔离条件与安全包线内允许抬升；任何非授权 / 越界触发被互锁阻止。

G2

单点失效后可安全落地

任一推力器、阀门或感知单点失效后，剩余控制能力足以保持姿态并受控落地。

G3

压力系统不发生不可接受爆破

COPV 在设计寿命、碰撞、热与充放循环条件下满足爆破裕度与泄漏可控要求。

G4

地面与乘员风险可控

隔离区、约束系统、喷流噪声控制与应急撤离，使第三方与乘员风险降至可接受水平。

关键安全需求（示例）与验证证据对应

安全需求对应目标验证方法证据状态
抬升前完成授权确认、场地清场与互锁检查G1 / G4联锁设计评审 + 侵入 / 误用场景测试未公开
推力器 / 阀门失效后自动重构分配并进入降级包线G2故障注入、HIL、外场失效试验未公开

残余风险与未决项

  • 压力等级、爆破裕度、循环寿命与检测方法未披露，G3 暂无论证基础。
  • 冗余架构、故障重构与独立监控未见公开说明，G2 无法评估。
  • 无适航 / 道路准入与运行许可证据，载人开放运行的合法性前提不成立。
  • 在上述证据补齐前，建议仅限受控场地、无围观暴露的工程试验状态。

安全 Go / No-Go 门槛与建议

S-Gate 1

危险与场景闭环

完成 FHA / HAZOP、场景清单与风险接受原则，高风险条目均有缓解措施。

S-Gate 2

压力与结构证据

COPV 爆破裕度、疲劳、碰撞、热与泄压证据齐备并通过评审。

S-Gate 3

故障安全验证

单点 / 多点失效注入、降级控制、冗余与共因分析、中止逻辑验证通过。

S-Gate 4

监管与运行闭环

明确道路 / 航空身份类别、运行许可、人员资质、保险与应急体系。

建议结论：在 S-Gate 1–4 至少部分公开证据之前，Roadster Rocket 应被视为“受控场地内的工程演示原型”，不具备载人开放运行或公共道路 / 空域使用的安全与监管基础。保留不确定性，比用愿望填补安全空白更专业。
